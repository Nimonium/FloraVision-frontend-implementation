# FloraVision - Botanical E-commerce

A high-fidelity botanical product landing page built for the frontend implementation test. This project focuses on a premium, dark-themed aesthetic with glassmorphic UI elements and smooth interactions.

**Live Demo**: [View Live Project on Vercel](https://flora-vision-frontend-implementatio.vercel.app/)

## Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Icons**: Custom SVG icons
- **Fonts**: Inter (UI) & Dancing Script (Decorative)

## Project Structure
- `src/components`: Reusable UI components (HeroBanner, TrendyPlants, TopSelling, etc.)
- `public`: Static assets including high-resolution plant PNGs and user avatars.
- `src/app`: Application routing and global layout.

## Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Nimonium/FloraVision-frontend-implementation.git
   cd FloraVision-frontend-implementation
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **View the site**:
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Development Notes
- **Design Fidelity**: Implemented with pixel-perfect precision following the provided design references.
- **Glassmorphism**: Leverages Tailwind's `backdrop-blur` and semi-transparent background utilities for a premium layered feel.
- **Responsive Design**: Optimized for desktop and tablet viewports as per the core requirements.
